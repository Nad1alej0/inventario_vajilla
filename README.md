# Inventario de Vajilla
Primera versión PWA móvil.

## Incluye
- Inicio con buscador
- Categorías visuales
- Filtros por uso
- Alta desde celular
- Cámara o galería
- Nueva categoría
- Informes PDF
- PWA instalable

## Para publicación real
1. Crear repo nuevo en GitHub.
2. Subir estos archivos.
3. Activar GitHub Pages.
4. Ejecutar `supabase-setup.sql` en Supabase.
5. Completar `config.js`.
6. Crear las cuentas de Nadia y Tiara.
